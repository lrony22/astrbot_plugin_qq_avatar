# QQ 头像库

从头像库更换 QQ 头像，支持 AI 自主选图、分账号定时轮换和可视化管理，复用已有 OneBot 连接。

需要 AstrBot 4.29+，以及支持 `set_qq_avatar` 的 OneBot 协议端。

## 安装与配置

在 AstrBot 插件管理中通过仓库地址安装，或上传插件 ZIP：

```text
https://github.com/lrony22/astrbot_plugin_qq_avatar
```

1. 打开插件配置，在「QQ 账号与头像库」中添加账号。
2. 平台实例 ID 填 AstrBot 中已有的 OneBot 实例 ID，QQ 号填该机器人自己的号码。`qq_bot_1`、`qq_bot_2` 仅为示例名称，需替换为实际值。
3. 头像库目录留空时，自动使用 `data/plugin_data/astrbot_plugin_qq_avatar/<QQ号>/`；也可填写 AstrBot 能读取的自定义目录。
4. 按需设置 AI 开关、轮换方式、定时规则和冷却间隔，保存并重载插件。

默认账号列表为空。双账号示例见 [config.example.json](config.example.json)，使用前替换平台 ID 和 QQ 号。头像保存在插件数据目录，升级插件时保留。

## 可视化头像库

从插件详情页或侧栏扩展功能打开「QQ 头像库」，选择需要管理的账号。

- 上传：支持多选或拖入 PNG、JPEG、WebP 原图，单张最大 5 MiB，同名文件不覆盖。
- 预览与改名：点击图片查看大图；改名保留后缀，并同步上次选择记录。
- 删除：确认后移除图库文件，QQ 当前头像保持不变。
- 更换：点击「设为头像」，查看执行结果和剩余冷却时间。

图片操作立即生效，无需重载插件。直接向目录放入图片时，仅读取第一层支持的图片文件；点击「刷新」更新列表。不同账号默认使用独立目录，自定义为同一目录时会共享图片。

## AI 自主选图

开启账号的 AI 自主选图后，模型可使用：

- `qq_avatar_library`：列出当前账号可选图片、上次选择与轮换设置。
- `qq_avatar_change(file_name)`：按完整文件名更换当前账号头像。

AI 根据文件名选图，建议命名为 `开心.png`、`晚安.jpg` 等有含义的名称。模型需支持工具调用；配置工具白名单时，需加入上述两个工具。

AI 只能操作当前对话所属账号的图库。定时轮换独立执行，无需调用模型。

## 定时与轮换

每个账号独立设置五段 Cron，默认时区 `Asia/Shanghai`：

| 规则 | 时间 |
| --- | --- |
| `0 9 * * *` | 每天 09:00 |
| `0 9,21 * * *` | 每天 09:00、21:00 |

定时规则留空表示关闭。星期中 `0`/`7` 为周日、`1` 为周一。轮换方式：`random` 随机选择，`sequential` 按文件名顺序选择，均跳过与上次相同的头像。

冷却默认 60 分钟，设为 `0` 可关闭冷却。按账号独立计时，AI、定时及手动更换共用；失败不计入冷却，重载插件后保留记录。定时任务可在 AstrBot 的任务页查看，规则在插件配置中修改。

## 命令

| 命令 | 作用 | 权限 |
| --- | --- | --- |
| `/头像库` | 当前账号的图片列表与设置 | 所有人 |
| `/换头像` | 按当前账号配置轮换一次 | AstrBot 管理员 |
| `/换头像 开心.png` | 选择指定图片 | AstrBot 管理员 |

英文别名为 `/avatar_library`、`/avatar_change`。手动命令不受 AI 开关限制，但仍遵守冷却。

「上次选择」仅记录本插件成功设置的图片，不会自动同步 QQ 客户端中的手动修改。
