# QQ 头像库

支持 AI 根据对话和人设，从当前账号的头像库选图更换 QQ 头像；支持每个账号独立定时轮换。适用于 AstrBot 4.29+ 与支持 `set_qq_avatar` 的 OneBot 协议端，已在 SnowLuma 2.4.0 上实测更换头像。

## 安装与配置

安装地址：`https://github.com/lrony22/astrbot_plugin_qq_avatar`

1. 在 AstrBot 插件管理中通过上述仓库地址安装，或上传插件 ZIP。也可把本目录放入 `data/plugins/astrbot_plugin_qq_avatar` 后重载。
2. 打开「QQ 头像库 → 插件配置」，在「QQ 账号与头像库」按需添加一个或多个账号。
3. 平台实例 ID 填已有的 OneBot 实例 ID，例如 `onebot`、`grok`；QQ 号填对应机器人自己的号码。
4. 头像库目录建议留空，插件会在 `plugin_data` 下按 QQ 号分别创建。放入 PNG、JPG、JPEG 或 WebP 图片，仅扫描目录第一层，单张不超过 5 MiB。
5. 配置 AI 开关、轮换方式、定时规则和冷却间隔，保存并重载插件。

可参考 [config.example.json](config.example.json)，将示例 QQ 号换成实际号码。默认账号列表为空，定时规则留空表示关闭。

`library_dir` 留空时，使用 AstrBot 的插件数据目录，自动按 QQ 号隔离：

```text
data/plugin_data/astrbot_plugin_qq_avatar/
├── <第一个机器人的QQ号>/
│   ├── 开心_晴天.png
│   └── 晚安_月亮.jpg
└── <第二个机器人的QQ号>/
    ├── 认真_工作.webp
    └── 开心_微笑.png
```

插件发布包只包含代码、配置定义与说明，用户头像保存在 `plugin_data` 中；升级插件时无需重新放置头像。配置示例同样使用默认目录，不包含部署机器的绝对路径。

如需自定义，`library_dir` 也可填写 **AstrBot 所在环境**能读取的目录。相对路径基于 AstrBot 运行根目录，不同账号可指定不同目录或共用一个目录。

图片通过 Base64 交给账号的现有 OneBot WebSocket 连接，不需要配置 HTTP 地址、Token 或新增容器挂载。即使 `grok` 账号未开启 HTTP API，也能使用。

## AI 自主选图

开启账号的 `ai_enabled` 后，会注册两个工具，并在该账号的模型请求中提示可以自主选图：

- `qq_avatar_library`：列出当前账号可选图片、上次选择与轮换设置。
- `qq_avatar_change(file_name)`：按完整文件名更换当前账号头像。

建议图片命名包含语义，例如 `开心_晴天_微笑.png`、`晚安_月亮.jpg`、`认真_工作.webp`，AI 根据文件名选择。插件不额外调用视觉模型识别图片。

AI 可以在已有对话中自主调用；没有对话时，由定时轮换执行随机或顺序选择，不会额外调用大模型。模型需支持工具调用；如人格设置了工具白名单，需加入上述两个工具。

AI 工具不提供跨账号参数：哪个账号收到消息，就只能更换哪个账号的头像。开启 AI 自主能力表示允许该账号在普通对话中自行从预设图库选图。

## 定时与轮换

每个账号独立设置五段 Cron，默认时区 `Asia/Shanghai`：

| 规则 | 时间 |
| --- | --- |
| `0 9 * * *` | 每天 09:00 |
| `0 9,21 * * *` | 每天 09:00、21:00 |
| `0 */6 * * *` | 每隔六小时的整点 |
| `0 9 * * 1-5` | 工作日 09:00 |

星期沿用 AstrBot 的标准 Cron 语义，`0`/`7` 为周日、`1` 为周一。`selection=random` 随机选择并避免连续重复；`sequential` 按文件名排序依次轮换。只有一张图且已设置过时跳过。

冷却间隔按账号分别保存，AI、定时和手动更换共用。失败不会推进轮换记录或冷却；断线或错误不会补发，等待下次触发。插件重载后恢复上次选择，定时任务随插件注册和清理，不会叠加。

定时任务使用 AstrBot 自带调度器，可在原有定时任务页查看执行情况；时间和启停请在插件配置中调整。调度任务每次启动重建，历史任务记录也会清理。更换不会向聊天发送通知。

## 命令

| 命令 | 作用 | 权限 |
| --- | --- | --- |
| `/头像库` | 当前账号的图片列表与设置 | 所有人 |
| `/换头像` | 按当前账号配置轮换一次 | AstrBot 管理员 |
| `/换头像 开心_晴天_微笑.png` | 选择指定图片 | AstrBot 管理员 |

英文别名为 `/avatar_library`、`/avatar_change`。手动命令不受 AI 开关限制，但仍遵守冷却。

「上次选择」只记录本插件成功设置的文件名；通过 QQ 客户端等其他方式修改头像后，该记录不会自动同步。
